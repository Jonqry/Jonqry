## Projetos

### [Simulador de Financiamento](https://github.com/Jonqry/simulador-financiamento)

Compara SAC e PRICE com seguros, CET e tabela de amortização, calcula o imóvel máximo que o cliente pode comprar e simula FGTS e evolução de obra. Projeto solo, com mais de 250 testes automatizados e testes de ponta a ponta com Playwright.

React, TypeScript, Vitest, Playwright. [Testar online](https://simulador-financiamento-blush.vercel.app)

[![Tela do simulador comparando SAC e PRICE](https://raw.githubusercontent.com/Jonqry/simulador-financiamento/main/docs/screenshot.png)](https://simulador-financiamento-blush.vercel.app)

### [CashFlow](https://github.com/Jonqry/cashflow-fullstack)

Controle de gastos da casa. API em C# com .NET 10 que valida as regras de negócio, e front-end em React com TypeScript. Protegi a API com base no OWASP API Security Top 10: login com JWT, senha salva só como hash, validação de entrada (que fechou uma falha de mass assignment), limite de tentativas e headers de segurança, com testes de integração.

C#, .NET, React, TypeScript, SQLite, JWT, xUnit.

### [Place Brokers](https://github.com/Arthurms-dev/PI4-Place-Brokers-Integrador-FrontEnd)

Plataforma de uma imobiliária real de Recife, feita em equipe de 5 no Projeto Integrador da Unicap. Fiquei com a área do corretor: empreendimentos, leads, clientes e agendamentos.

React, Tailwind, Node.js, Supabase. [Site publicado](https://placebrokers-frontend.vercel.app)

### [Currículo Express](https://github.com/Jonqry/curriculo-express)

API REST de currículo com Node.js, Express e PostgreSQL. [Testar a API](https://curriculo-express-eta.vercel.app)
